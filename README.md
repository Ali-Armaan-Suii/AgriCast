## 📖 প্রজেক্ট পরিচিতি (Project Overview)

**AgriCast (এগ্রিকাস্ট)** একটি রিয়েল-টাইম এগ্রো-স্পেস এনালিটিক্স প্ল্যাটফর্ম, যা মার্কিন মহাকাশ গবেষণা সংস্থা **NASA Earth Science**-এর কৃত্রিম উপগ্রহ মিশনগুলোর ডেটাসেট বিশ্লেষণ করে কৃষকদের প্রতিকূল আবহাওয়া, মাটির আর্দ্রতার ঘাটতি, দাবানল, এবং খরা থেকে ফসল রক্ষার আগাম সিদ্ধান্ত নিতে সহায়তা করে।

প্ল্যাটফর্মটি সাধারণ কৃষকদের ব্যবহারের সুবিধার্থে বাংলাদেশের সবচেয়ে জনপ্রিয় ও সহজবোধ্য **বিকাশ (bKash) মোবাইল ডিজাইন ল্যাঙ্গুয়েজ** অনুসরণ করে তৈরি করা হয়েছে—যার মধ্যে রয়েছে রঙিন ভেক্টর SVG সমৃদ্ধ **"অন্যান্য সেবাসমূহ"** ড্যাশবোর্ড, ৪ সেকেন্ডে অটো-কলাপ্সিং **"ব্যালেন্স দেখুন"** আর্দ্রতা ক্যাপসুল, এবং স্থানীয় বাংলা কণ্ঠে **অডিও ভয়েস বুলেটিন**।

## 🛰️ নাসা আর্থ সায়েন্স মিশন ডেটাসেট (NASA Satellites & Datasets Pipeline)

AgriCast প্ল্যাটফর্মটি সরাসরি নাসার ওপেন সায়েন্স এপিআই এবং আর্থ সায়েন্স মিশনের সাথে সংযুক্ত:

1. **NASA POWER (Prediction of Worldwide Energy Resources)**:
   - সোলার রেডিয়েশন (ALLSKY_SFC_SW_DWN), সর্বোচ্চ/সর্বনিম্ন তাপমাত্রা (T2M_MAX, T2M_MIN), বাষ্পীভবন (Evapotranspiration), এবং আগামী ৫ দিনের কৃষি পূর্বাভাস।
2. **NASA SMAP (Soil Moisture Active Passive L-band Radar)**:
   - ভূপৃষ্ঠের ০–৫ সেমি গভীরতার তাৎক্ষণিক আর্দ্রতা এবং শিকড় অঞ্চলের (Root-Zone Soil Moisture) পানির ভারসাম্য।
3. **NASA ECOSTRESS (Thermal Infrared on ISS)**:
   - উদ্ভিদের ক্যানোপি তাপমাত্রা (Evaporative Stress Index) দ্বারা আকস্মিক খরা ও ফসলের তাপীয় চাপ নির্ণয়।
4. **NASA GPM (Global Precipitation Measurement Core Observatory)**:
   - মিলিমিটার এককে বৃষ্টিপাতের সঠিক হার এবং মেঘের জলীয় ঘনত্বের পরিমাপ।
5. **NASA-ISRO NISAR (L-band & S-band SAR Radar)**:
   - ঘন মেঘ ও কুয়াশা ভেদ করে রাডার ইন্টারফেরোমেট্রি দিয়ে মাটির গঠন ও অভ্যন্তরীণ পানির স্তর ম্যাপিং।
6. **NASA FIRMS (MODIS / VIIRS 375m)**:
   - সক্রিয় দাবানল, জমিতে নাড়া পোড়ানো এবং থার্মাল হটস্পট এনোম্যালি পর্যবেক্ষণ।

## 📱 বিকাশ-অনুপ্রাণিত ৮টি প্রধান সেবা (bKash-Style 8 Services Grid)

হোমপেজে থাকা বিকাশ স্টাইল **"অন্যান্য সেবাসমূহ"** কার্ডে ৮টি স্বতন্ত্র রঙিন ভেক্টর SVG অন্তর্ভুক্ত:

* 🌾 **আমার জমি (My Field)**: কৃষকের নির্দিষ্ট প্লটের সীমানা, অবস্থান এবং মাটির স্তরভিত্তিক ডাটা।
* 🩺 **স্বাস্থ্য স্কোর (Health Score)**: লাইভ মেডিকেল ইসিজি পাল্স এবং পাতার এনডিভিআই (NDVI) অ্যানালাইসিস।
* 🛰️ **নিসার রাডার (NISAR Radar)**: মেঘাচ্ছন্ন বা বর্ষার রাতেও রাডার তরঙ্গের সাহায্যে মাটির স্যাচুরেশন ডাটা।
* ⚠️ **জরুরি সতর্কতা (Urgent Alert)**: আকস্মিক বন্যা, বজ্রঝড় ও কালবৈশাখীর আগাম নোটিফিকেশন।
* 🎛️ **হোয়াট-ইফ (What-If Sim)**: তাপমাত্রা বা বৃষ্টিপাত পরিবর্তিত হলে ফসলের উপর প্রভাব যাচাইকারী ইন্টারঅ্যাক্টিভ সিমুলেটর।
* 🔥 **আগুন সতর্কতা (Fire Alert)**: নাসা ফার্মস স্যাটেলাইটের থার্মাল হটস্পট রাডার ও দূরত্ব নির্ণয়।
* 📋 **ফসল রোডম্যাপ (Crop Roadmap)**: ধানের শিষ ও স্থানীয় ২৫+ ফসলের (ব্রি ধান, গম, পাট, সরিষা) বপন থেকে ফলন পর্যন্ত ধাপ।
* 🔬 **মাটি স্ক্যান (Soil Scanner)**: স্মার্টফোন ক্যামেরার অপটিক্যাল স্পেকট্রাল রেন্ডারিং দিয়ে মাটির গঠন ও NPK পুষ্টি বিশ্লেষণ।

## ⚡ রান ও বিল্ড করার নিয়মাবলী (Setup & Execution Guide)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন (Port 3000):
```bash
npm run dev
```
ব্রাউজারে ভিজিট করুন: `http://localhost:3000`

### ৩. টাইপচেকিং ও লিন্টিং:
```bash
npm run lint
```

### ৪. প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
```
বিল্ড আউটপুট `dist/` ফোল্ডারে জেনারেট হবে।
