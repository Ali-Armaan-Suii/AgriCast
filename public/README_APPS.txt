============================================================
   এগ্রিকাস্ট (AgriCast) - Standalone Applications
============================================================

এই জিপ ফোল্ডারে আপনার অ্যাপের জন্য ২টি স্বতন্ত্র অ্যাপ্লিকেশন ফাইল রয়েছে:

১. agricast.apk (Android Mobile App)
   - ফাইল: khetdrishti.apk / agricast.apk
   - প্ল্যাটফর্ম: Android 5.0+ (Lollipop to Android 15)
   - বিবরণ: অ্যান্ড্রয়েড মোবাইলের জন্য সরাসরি ইনস্টলযোগ্য Native APK ফাইল।
     ফোনে নিয়ে ক্লিক করে Install দিলেই 'AgriCast' একটি স্বাধীন অ্যাপ হিসেবে চালু হবে।
     কোনো গুগল ক্রোম বা ওয়েব ব্রাউজার দরকার নেই।

২. khetdrishti.exe (Windows Desktop App)
   - ফাইল: khetdrishti.exe
   - প্ল্যাটফর্ম: Windows 10 / Windows 11 (64-bit)
   - বিবরণ: উইন্ডোজ কম্পিউটারের জন্য স্বতন্ত্র এক্সিকিউটেবল ফাইল।
     ডাবল ক্লিক করলেই সরাসরি স্বতন্ত্র অ্যাপ উইন্ডোতে রান করবে।
